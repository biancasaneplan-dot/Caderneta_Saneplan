# Caderneta_Saneplan
Caderneta de Campo da Saneplan: aplicativo de registro de campo para visitas técnicas de planos municipais nos quatro eixos do saneamento (água, esgoto, resíduos e drenagem). Tira fotos com a coordenada do GPS no momento do disparo, organiza pontos, relatos e reuniões, e exporta um pacote com fotos numeradas e dados para o QGIS.
